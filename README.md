# 🎓 Smart Academic Enquiry Consultant

An AI-powered academic enquiry assistant designed to provide instant, accurate, and contextual responses to student queries regarding admissions, academics, campus facilities, placements, scholarships, and other institutional information.

The system leverages Large Language Models (LLMs) and modern web technologies to automate academic support while improving accessibility and user experience.

# ⚙️ How It Works

1. User submits a query through the chat interface.
2. Backend processes the request.
3. Institutional information is retrieved.
4. The LLM generates a contextual response.
5. The response is returned to the user in real time.
